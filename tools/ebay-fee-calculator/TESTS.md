# eBay Fee Calculator tests (2026-10-29 PM sprint, node on extracted functions; scratchpad test_ebay.js, all PASS)
Rule source: ebay.com/help/selling/fees-credits-invoices/selling-fees?id=4822, read 2026-10-29 in Chrome. Basic (non-Store) US: FVF on "total amount of the sale" (item + handling + buyer-paid shipping + sales tax + other fees); per-order fee $0.30 if order <= $10, $0.40 if > $10. Rates: most 13.6% to $7,500 then 2.35%; books/movies/music 15.3%; select collectibles (trading cards, comics) + coins 13.25%; athletic sneakers 8% and no per-order fee at $150+, else 13.6%; women's bags 15% <= $2,000 else 9%; jewelry 15% <= $5,000 else 9%; watches 15% to $1,000, 6.5% to $7,500, 3% above; guitars & basses 6.7% then 2.35%.
Modeling choice: tax = rate x (price + shipping charged), rounded to cents; FVF rounded half-up to cents. Some states don't tax shipping (FAQ says so).
Defaults ($40, free shipping, $7.50 label, 7% tax, cost 10, extra 1, target 15, want 30): tax 2.80, total 42.80, FVF 5.82, per-order 0.40, fee 6.22, earn 26.28, profit 15.28, lowest offer 39.67 (earn exactly 26.00; 39.66 gives 25.99), list at 44.35. Fee on tax 0.38.
Hand cases: media $20 + $5 ship, 0 tax -> FVF 3.83 (3.825 half-up), fee 4.23; $8 order -> 1.09 + 0.30; $10.00 order -> $0.30, $10.01 -> $0.40; sneakers $150 -> $12.00 no order fee, $149.99 -> 20.40 + 0.40; watches $2,000 -> 215.40; most $10,000 -> 1,079.15; bags $2,500 -> 225.40; guitars $1,000 -> 67.40.
Brute force: 54,440 priceFor calls (8 categories x 5 shipping/tax/label combos, needs $0.01-$250): payout >= need and no cheaper cent price (prefix max of earn over all cents) reaches it: 0 failures. Payout drops only where the order total crosses $10 (per-order step): 0 unexpected drops over $0.01-$400 in all 40 combos.
Zero/garbage: price 0 -> all $0.00, no NaN. Tax capped at 25%, money inputs capped at $1M.
